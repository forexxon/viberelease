# Vibe Release

Public MVP for **viberelease.ru**.

Vibe Release is a release-readiness service for AI/vibe-coded products built with tools such as Cursor, Claude Code, Lovable and Supabase.

## Beta offer

- 12–15 relevant MUST PASS tests
- Release verdict: BLOCK / LIMITED / READY within agreed scope
- Evidence for findings
- Fix priority
- One Critical/High retest

## Important boundary

Vibe Release is not a guarantee of absolute security, a full penetration test, or a legal opinion.

## Publishing

This repository is intended to be deployed as a static site with GitHub Pages and custom domain `viberelease.ru`.
