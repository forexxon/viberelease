## 2. INFERENCE — где должен стоять Vibe Release

Vibe Release не должен конкурировать:
- с мелкой почасовой правкой за 1–5k;
- с автоматическим scanner за $0–9;
- с крупной студией через обещание «мы просто пишем код».

Оплачиваемая ценность Vibe Release:
1. квалифицировать текущее состояние;
2. доказать проблему;
3. зафиксировать rollback;
4. исправить в согласованном объёме;
5. выполнить recheck;
6. довести до заранее согласованного acceptance test.

Следовательно, коммерческая единица должна быть не «час разработчика», а **фиксированный outcome-sprint**.

## 3. DECISION V1 — продуктовая лестница

### FREE — 0 ₽
Что получает клиент:
- stage routing: IDEA / STUCK / READYISH;
- estimated readiness / complexity;
- Top-3 areas;
- mini-scope / next-step map;
- AI-ready prompts там, где self-fix безопасен;
- после результата — возможность получить бесплатный scoping artifact.

Задача FREE: qualification + trust + lead context. Не заменяет платную проверку.

### CHECK — стандартная проверка перед запуском
Beta: **8 900 ₽** для первых 5 подходящих стандартных проектов.

Scope baseline:
- 1 продукт;
- 1 основной repo;
- 1 staging/prod env;
- до 2 основных ролей;
- 1 DB;
- 1 payment integration;
- ~12–15 must-pass сценариев;
- локальные безопасные исправления в согласованном scope;
- 1 основной fix cycle + recheck;
- итоговый launch verdict по протестированной версии.

Правило V1: 8 900 ₽ не использовать для unlimited development. Если finding требует крупной разработки — перевод в FINISH с новым фиксированным scope до изменения кода.

### FINISH — довести начатый проект
Не публиковать один фиксированный чек для всех проектов.

Внутренний routing V1:
- **FINISH Micro**: 15–25k ₽ — локальный ограниченный outcome, примерно 1–2 рабочих дня;
- **FINISH Sprint**: 30–60k ₽ — несколько связанных blockers / 3–5 рабочих дней;
- **FINISH Major**: 60k+ ₽ — уже почти development project; после repo review выдаётся fixed scope/price/time.

Почему такой коридор:
- ниже 15k находится массовый task-market FL.ru, где покупают отдельные маленькие правки;
- 30–60k пересекается с нижним рынком done-for-you и bot/product work;
- 60–100k начинается зона студийных MVP/automation offers.

Это **pricing decision**, не статистический средний чек.

### BUILD — от идеи до рабочего продукта
Публично на первом этапе лучше показывать **"от" и рыночный диапазон**, а точную цену давать после free scope.

Внутренний floor V1:
- лендинг / простой сайт: **от 30k ₽**;
- простой Telegram-бот / интеграция: **от 40–60k ₽**;
- AI-ассистент / automation: **от 60k ₽**;
- внутренний сервис / CRM: **от 70–90k ₽**;
- SaaS MVP: **от 80–120k ₽**;
- сложный SaaS / платформа: **от 150–200k ₽**;
- mobile/PWA с backend: **от 100k ₽**.

Эти floors привязаны к публичным предложениям AVAT / MKDGRUPP / CraveCode, но не являются обещанием сделать любой проект за минимальную цену.

### CARE — после запуска
Не запускать как основной тариф до первых клиентов.
Варианты после validation:
- on-demand: 2.5–4k ₽/час;
- fixed maintenance sprint;
- monthly monitoring/release-check.

Рыночный anchor: AVAT публично указывает поддержку 2 500 ₽/час.

## 4. IDEA calculator — что можно показывать до заявки

Нельзя выдавать ложную «точную цену». Результат должен выглядеть так:

- **ориентир от X ₽**;
- **типичный срок от Y**;
- подпись: `Точная цена и acceptance scope фиксируются после бесплатного разбора. Ориентир меняется, если меняется объём.`

### Base floors по type
- landing = 30k / 3–5 дней
- bot = 45k / 3–7 дней
- integration = 45k / 3–7 дней
- assistant = 60k / 5–10 дней
- crm = 75k / 5–10 дней
- saas = 80k / 5–14 дней
- mobile = 100k / 2–4 недели
- other = ручная оценка

### Complexity adjustment — только для диапазона, не для договора
- SIMPLE: base floor
- STANDARD: base × 1.35–1.75
- COMPLEX: base × 1.8–2.75

Важно: multiplier — **Vibe Release decision для estimator UX**, не рыночная статистика. Перед публикацией проверить минимум на 10 реальных входящих задачах, сравнив estimate с фактическим scope.

## 5. Коммерческое правило, которое копируем у сильных игроков

1. Клиент получает value бесплатно.
2. Затем scoping.
3. До оплаты фиксируем output и acceptance test.
4. Цена фиксируется на scope, а не на абстрактное «доделать всё».
5. Изменение scope = отдельное согласование.
6. CHECK fee при переходе в крупный FINISH можно частично/полностью зачесть в последующую работу — протестировать как conversion mechanism после первых 5 CHECK.
7. Repo/code остаётся у клиента.
8. Recheck обязателен для закрытия outcome.

## 6. Что ещё не подтверждено

Пока нет собственных данных Vibe Release по:
- lead→sale conversion;
- среднему времени CHECK;
- среднему FINISH scope;
- willingness-to-pay;
- доле CHECK→FINISH;
- CAC;
- возвратам/переработкам;
- фактической марже.

Поэтому этот V1 — не финансовый forecast. Это **рынком ограниченный стартовый прайс**, который нужно обновлять после каждой из первых 10 продаж/отказов с причиной отказа.
