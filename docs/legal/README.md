## Что подтверждено по действующим источникам на 13.08.2026

1. Физическое лицо может быть оператором персональных данных, если самостоятельно определяет цели и состав обработки.
2. При сборе персональных данных через интернет оператор должен обеспечить доступ к политике обработки персональных данных на страницах, используемых для такого сбора.
3. По ст. 22 152-ФЗ оператор до начала обработки обязан уведомить Роскомнадзор, кроме оставшихся узких исключений; одно из них — обработка исключительно без средств автоматизации.
4. Для НПД отдельная ККТ не требуется, но чек по полученному доходу формируется через «Мой налог» и передаётся заказчику.
